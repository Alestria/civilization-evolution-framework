# 案例试编码一页清单

先填一小组有代表性的观察，包括好编码、容易混淆和缺资料的记录。正式方法与每项命题的失败条件见[蓝图 §14](../docs/v0.4.3.md#十四变量操作化证伪与边界条件)。试编码用于确定字段、来源和观察边界。

| 步骤 | 最少填写 |
| --- | --- |
| 1. 画出范围 | 命题编号、观察单位、双方方向、参照功能、基准窗、后续窗、纳入与排除依据。韧性案例分别锁定资产清册、焦点组织、功能边界和冲击类型。 |
| 2. 锁定比较 | 处理和对照、主结果、预测方向、最小实质差异及失败条件。记录哪些条件必须可比，哪些只作竞争解释。 |
| 3. 分开取证 | 每个观测写来源编号、事实编号、字段位置、形成时间及取值。已知历史结局须在记录中注明。 |
| 4. 处理缺失 | 有足够反证才能记缺失或确认未发生。资料、身份或时序不能核实时记“不明”。NP 只用于证据足以认定无可行路径的边界。 |
| 5. 检查重叠 | 对 Dep/SD、B/K、Ctrl/Ct 分别列共同与合并的来源数和事实数。登记是否能删去共用材料或换独立指标复算。任一端缺档时记“不可评估”。 |
| 6. 独立复编 | 两名编码者分别用同一口径记录原始判断，再对照。按条保留分歧、解决依据及仍不明项。一次小样本 AI 复核可用于校准，完整双人编码另行记录。 |
| 7. 定用途 | 标记“可进入方向性研究设计”“仅联合描述或过程追踪”或“资料不足”。若关键变量只依赖同一事实，结论仅作联合描述。记录下一项最有区分力的资料。 |

**最短记录行**

| 单位与日期 | 变量与取值 | 来源编号、事实编号、定位 | 缺失或除外 | 编码者与复核 |

**容易错判的三个情形**

- H7 先据事前材料确认机会，再核实是否实施。最终清单可观察公开纳入，机会分母或确认未实施缺失时，实施率不可估计。
- H9 先固定两支的成员或任务映射，再分别记录实际互操作和共同行动。用更严的映射复算。共有源代码、单方移植、倡议和共同交付分别编码。
- H4 无适配冲击的窗口只登记常态成本分项。H8 同时固定资产盘点边界和功能边界，按各自门槛报告资产存续与功能损失。
