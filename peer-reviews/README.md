# 审查记录

本目录记录框架收到了哪些质疑、哪些问题已在稿件中处理，以及哪些判断仍依赖新证据。可从 [V0.4.2](../docs/v0.4.2.md) 与 [V0.4.3](../docs/v0.4.3.md) 对照查看变更。

## V0.4.3 的两条审查路径

两份 AI 审查分别聚焦理论架构，以及研究设计、证据与符号。以下是公开摘要。

| 审查重点 | 修订回应 | 待核查事项 |
| --- | --- | --- |
| 理论原理的分析作用，集体主体的证据边界 | 将开放性和差异性列为框架预设。增加对认知、目标及治理的分离取证规则 | 用具体案例检验判据在临时网络、非正式协调和资料不齐时是否适用 |
| 依赖、控制、瓶颈、替代路径与成本的重复计入 | 分开登记观测值、资料来源及推导关系。明确缺失与不可比规则 | 用独立资料试编码，检查共享代理指标是否仍造成重复计入 |
| H1–H9 的反驳标准，以及 H1 和 H7 的时间与证据口径 | 针对每项命题写明最低可比条件、预期结果和失败情形。H1 要求事前基准，H7 区分未知与有证据支持的未实施 | 核对各案例能否提供必要档案，校准门槛并完成研究预登记 |

更完整的逐项对应见 [V0.4.3 的 §18.4](../docs/v0.4.3.md)。这些反馈属于 AI 辅助的框架审查。概念与架构仍待复审和确认，九项经验命题的证据等级仍为「尚未独立检验」。

## 提交新的审查

请注明所审版本及具体章节或命题，区分术语、研究设计、资料与推断方面的问题。若建议修改结论，请附可追溯来源、反例或可操作的检验办法。建议格式见 [参与方式](../CONTRIBUTING.md)。
