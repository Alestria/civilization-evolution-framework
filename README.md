# 文明分化与整合演化哲学

这是一个开放的哲学研究项目。它研究文明中的主体、关系与制度如何分化、协调、断裂与重组，并尝试把相关解释转化为可以接受反例检验的命题。

**当前版本为 V0.4.3 复审后的冻结候选稿。** 概念与架构待作者签署，H1–H9 均尚未得到独立检验。案例档案用于试编码和核查资料可得性，证据状态以蓝图的命题—证据矩阵为准。
