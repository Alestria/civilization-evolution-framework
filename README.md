# 文明分化与整合演化哲学

这是一个开放的哲学研究项目。它研究文明中的主体、关系与制度如何分化、协调、断裂与重组，并尝试把相关解释转化为可以接受反例检验的命题。

**当前版本为 V0.4.3 双审修订稿。** 概念与架构待进一步复审，H1–H9 均尚未得到独立检验。两份 AI 审稿用于改进框架与研究设计，证据状态以蓝图的命题—证据矩阵为准。
