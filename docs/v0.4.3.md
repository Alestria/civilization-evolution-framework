# 一、理论定位与研究边界

## 1.1 本理论试图回答什么

【理论定位】

《文明分化与整合演化哲学》研究：**不同层次的主体在资源条件、权力结构和连接机制的约束下，如何形成差异、建立协作、维持自主性、发生关系断裂，并重组各自及共同系统的结构。**

理论的起点是一个经验问题：在同一时期，技术、贸易和知识网络可能持续连接，而政治、安全和身份关系也可能出现对立、退出或断裂。以“人类终将统一”或“世界必然分裂”概括这一现实，容易抹平不同领域、层级和时间尺度之间的差别。

本理论的目标不是预测文明的终极形态，而是建立一组可修订的分析工具，用于：

1. 描述主体、资源和关系结构；
2. 区分连接、依赖与规则与协调整合；
3. 识别结构优势转化为权力的条件；
4. 分析脆弱性、韧性及其动态变化；
5. 将解释转化为可接受反例检验的条件性命题。

“结构诊断”在此指有边界、有证据等级的分析活动，不意味着本框架已经形成成熟的定量诊断量表。

## 1.2 文明与主体

【定义 D1｜文明】

本书将**人类文明** 界定为跨个体、组织与区域持续再生产的社会技术关系及支撑这些关系的资源流动、知识、规则和基础设施。个体、组织及其他行动单元按 D2 和 §5 的独立判据认定。自然环境作为约束与交换对象。研究者须说明系统的观察边界以及纳入模型的物质、能量和信息交换。

这里的“系统”是一种研究视角，不预设文明具有统一意志、共同目标或单一控制中心。

【定义 D2｜文明主体】

**文明主体** 是在特定研究问题中，具有可识别边界，并能够在一定程度上组织资源、形成行动和与外部发生关系的分析单元。

个体、企业、国家、开源项目、宗教组织和国际组织等均可能成为分析主体。群体具有共同身份，并不自动意味着其具有统一目标或集体行动能力。

## 1.3 研究对象与限制

本理论关注社会技术系统中的关系、规则、资源、权力和行动；自然环境是重要约束与互动对象，但本书不以取代生态学、物理学或其他专门学科的解释为目标。

理论能够用于跨领域比较，但任何具体应用都必须说明：

- 研究对象与观察边界；
- 主体、资源、关系和结果所处的层次；
- 研究时段与冲击情景；
- 研究者选取的功能和评价标准；
- 证据来源、不确定性与替代解释。

本理论不预设全球整合优于地方自主，也不预设集中或分散必然更有效、更公平或更安全。效率、安全、公平、自主和稳定可能彼此冲突，其权重属于需要说明的规范选择。

## 1.4 跨层推导的边界

【方法要求】

从个体、组织、国家或全球层级中的一种现象，推导另一层级的结果时，必须交代**传导机制、作用路径和尺度转换条件**。

例如，国家政策可能通过出口许可影响企业采购，再通过供应约束影响另一国的生产能力。但如果缺少这些中间环节，就不能直接从“国家之间关系紧张”推出“全部企业关系断裂”。

“跨层不可还原性”在本书中的含义是：不同层级不能未经论证地相互等同。它不意味着跨层因果解释不可能，也不预设所有宏观现象都无法由微观机制解释。

# 二、四层理论架构与研究纪律

## 2.1 四层理论架构

四层是理论的逻辑组织方式，不等同于全书的五篇结构。

| 理论层 | 主要问题 | 内容 | 修订方式 |
|---|---|---|---|
| 第一层：基础哲学 | 研究对象如何存在，我们如何认识它？ | 开放性、异质性、多层次、分化、整合、相互作用及非目的论 | 相对稳定；遇到逻辑矛盾、持续解释失败或基础假设失当时修订 |
| 第二层：结构模型 | 系统由什么构成，关系如何分布？ | 主体、资源、关系、整合、权力、替代距离、韧性 | 随概念审计、操作化和案例比较修订 |
| 第三层：动态机制 | 结构如何影响行动与变化？ | 反馈、武器化、分叉、隔离、效率—韧性关系、共演化 | 依据过程证据、对照案例与反例修订 |
| 第四层：研究与检验 | 如何判断理论是否有解释力？ | 操作化、比较研究、证伪、证据矩阵与案例 | 随数据质量、研究设计及结果持续更新 |

**结构状态不自动等于动态机制。** 例如，跨层整合差异是结构描述。它是否增加脆弱性，需要检验具体机制与条件。

## 2.2 六类理论内容的强制区分

全书的核心段落、章末总结及命题矩阵，应使用以下标签：

| 标签 | 含义 | 能否直接凭案例“证明” |
|---|---|---|
| **定义** | 规定本书如何使用某个术语 | 定义本身不由案例证实；可因含混、不适用或不一致而修订 |
| **原理** | 理论采用的基础性认识与工作假设 | 应检查内部一致性与经验适用性；不同表述的可检验程度不同 |
| **机制** | 提出从条件到结果的可能作用过程 | 需要过程证据，不能只凭起点和结果同时出现认定 |
| **命题** | 对特定条件下可能关系的明确判断 | 可以设计观察和反例检验 |
| **假说** | 尚待检验的候选解释或预测 | 应说明预期证据、替代解释与可能失败条件 |
| **案例** | 用于描述、比较和检验的现实材料 | 案例本身不是理论结论，也不自动代表所有系统 |

【方法要求】每章末尾应列出：

1. **本章理论定位：** 本章建立了哪些定义、原理、机制、命题或假说；
2. **核心思想脉络注记：** 相关思想来源、对话对象以及本书与既有研究的区别；
3. **命题矩阵索引：** 本章提出或使用的命题编号及当前证据状态。

H 系列统一登记经验主张，正文按成熟度标注【命题】或【假说】。框架预设和方法论原则独立登记。

## 2.3 全书方法论纪律

1. **不预设历史终点。** 不把全球统一、永久分裂、持续进步、永久和平或某种制度视为必然归宿。
2. **不预设单一因果解释。** 允许技术、制度、经济、安全、文化与主体选择的解释相互竞争。
3. **区分结构、行动与结果。** 不从依赖直接推出胁迫，不从控制能力直接推出控制行为。
4. **区分关联与因果。** 对可能的反向因果、共同原因和选择效应提出检验。
5. **案例既用于建构，也用于反驳。** 应寻找不符合预期的案例，不能只选择支持理论的材料。
6. **承认概念的不整齐。** 分化未必形成清晰边界；连接未必产生合作；整合未必带来稳定；开放未必促进进步。
7. **不把模型变量误作现实整体。** 每个向量只是围绕特定问题的描述工具，遗漏的变量必须公开。
8. **基础理论也可修订。** 但定义、规范原则和经验假说的修订依据不同，不能混称“被证伪”。
9. **禁止虚假精度。** 不将示意数值当成测量结果，不以无依据的综合分数掩盖维度差异。
10. **建立可追溯性。** 重要事实、历史判断和理论归属须有可核查来源；未核实内容明确标记。

# 三、两项框架预设、四项基础原理与一项方法论原则

框架预设规定建模时允许纳入的条件。基础原理提出组织分析的工作判断，具体经验后果须另立命题。非目的论独立登记为方法论原则。

- **P3 多层次性** 要求指出判断所处的层次，并说明跨层传导机制，见 §1.4。
- **P4 分化与 P5 整合** 划定演化的可能路径。现有系统内可能产生新分工，异质主体也可能形成稳定协调。两项原理分别排除预设的单向同质化和差异必致隔绝，不给出发生概率或方向性预测。
- **P6 相互作用** 允许分化和整合互相反馈。反馈的方向、传导条件和可被反驳的观察结果由具体机制和命题承担，见 Mech1 及 H3。

## 框架预设一：开放性

【框架预设 FP1】

模型允许物质、能量、信息、知识和规则跨越观察边界。研究者应说明忽略何种交换在给定时窗与误差容限内仍足以解释结果。若主张某项交换会改变结果，应设置可比较的近似封闭模型，并预先指定交换指标、传导环节和结果变量。

## 框架预设二：差异性

【框架预设 FP2】

模型允许主体之间及其内部存在资源、认知、目标、能力与身份差异。将其处理为近似同质时，应说明忽略哪些差异、允许何种误差。若主张某项差异改变结果，应事先提出异质模型和同质近似的不同预测，交由具体研究比较。

## 基础原理 P3：多层次性

【原理 P3】

文明中的行动与关系跨越多个相互嵌套、交叉但不完全同构的层次；同一时期不同层级可呈现不同的分化与整合状态。

观察层次可包括全球、国家或超国家、区域与社会、组织与共同体、个体等。它们是分析划分，不是唯一合法的固定层级。

## 基础原理 P4：分化

【原理 P4】

在环境变化、主体互动和内部调整中，系统能够产生或强化不同的角色、能力、组织形式、身份和发展路径。

分化不必然意味着关系断裂、明确边界或整体能力提高。

## 基础原理 P5：整合

【原理 P5】

具有差异的主体能够通过规则、标准、互认、信任或协调机制，形成一定程度的持续协作与共同运行能力。

整合不必然要求单一中心、政治统一、完全消除差异或普遍让渡自主权；但具体整合可能涉及权力让渡、依赖或排斥，必须具体分析。

## 基础原理 P6：相互作用

【原理 P6】

分化与整合能够改变彼此的条件、成本和发展方向；二者可能相互促进、相互抑制，也可能在不同时期呈现不同关系。

这是一项关系性工作假设，不规定所有变化都能归因于分化—整合反馈。

## 方法论原则：非目的论

【方法论原则 MP1】

不以预设的终点解释文明演化。对任何结果的解释都应结合当时可观察的结构条件、行动选择、偶然事件与反馈过程。

行动者当时可知且有证据支持的目标可以进入因果解释。若用未来结果回推当时的行动原因，须另举当时可获得的信息、意图和传导证据。第 5 章据此区分行动者目的、事后结果与历史必然性。

# 四、核心概念：过程、状态与关系

## 4.1 分化与分裂

【定义 D3｜分化过程】

```math
D_{\mathrm{proc}}
```

指主体、角色、能力、功能、身份或发展路径产生、强化差异的过程。

【定义 D4｜分化状态】

```math
D_{\mathrm{state}}
```

指在特定时点和观察尺度下，系统内部差异的结构状态。

【定义 D5｜分裂过程】

```math
F_{\mathrm{proc}}
```

指已有的组织关系、共同规则、互认机制或重要连接发生实质削弱、退出、中断或断裂的过程。

【定义 D6｜分裂状态】

```math
F_{\mathrm{state}}
```

指特定时点相对于明确历史基准所观察到的关系削弱或断裂状态。

**边界规定：**

- 争论、竞争或利益分歧本身不必然构成分裂。
- 不同主体变得更不相似，不必然意味着既有连接发生断裂。
- 关系断裂也可能发生在没有显著新增分化的情形中。
- 状态需要指定基准：谁与谁、何种关系、相对于何时、改变到什么程度。

## 4.2 连接、依赖、整合与共演化

【定义 D7｜连接】主体之间存在物质、人员、资金、知识、信息或其他资源流动的通路及其使用关系。连接可以存在而不产生合作。

【定义 D8｜依赖】主体在维持指定功能或实现目标时，对另一主体、资源、节点或关系的需求程度。依赖需注明方向、参照功能和基准期。经验研究按 §14.2 独立编码既有投入、服务或合同暴露，另行记录替代路径和迁移成本。

【定义 D9｜整合】主体通过规则、标准、互认或协调安排，形成持续、可预期的跨主体共同运行或协作能力的过程及其相应状态。整合可依托正式规则，也可依托有重复行为和稳定预期支持的非正式惯例。后者至少需记录重复参与、违背后如何协调或修复，以及适用边界。一次性配合与纯流量增长可另作描述。公平和稳定须分别观察。

【定义 D10｜共演化】多个主体或子系统通过持续互动，改变彼此的约束、选择或发展路径。共同变化本身不足以证明相互造成变化。

分化、分裂、连接与整合可以并行发生。概念上的并行可能性本身无法推出某一收敛终点。第 5 章据此区分事后结果与产生该结果的历史机制。

# 五、主体六元模型与主体资格判据

## 5.1 六元描述模型

【定义 D11｜主体模型】

对主体 $`i`$ 在时点 $`t`$ 的工作性描述为：

```math
\boxed{
\mathcal{A}_{i,t}
=
\left(
Bd_{i,t},
Rs_{i,t},
Cog_{i,t},
Goal_{i,t},
O_{i,t},
J_{i,t}
\right)
}
```

| 分量 | 名称 | 核心问题 |
|---|---|---|
| $`Bd`$ | 边界 | 谁被视为主体内部成员，哪些活动或资源属于其范围？ |
| $`Rs`$ | 资源池 | 主体能够取得、组织或使用什么？ |
| $`Cog`$ | 认知结构 | 主体或其内部不同部分如何理解环境、风险与可选行动？ |
| $`Goal`$ | 目标集合 | 主体内部有哪些目标、利益及优先顺序，彼此是否冲突？ |
| $`O`$ | 内部治理 | 主体如何协调、决策、分配资源并处理内部冲突？ |
| $`J`$ | 外部接口 | 主体如何与外部交换资源、信息、规则或作出承诺？ |

$`Cog`$、$`Goal`$ 与 $`O`$ 必须分开：理解同一环境的主体可以作出不同目标选择；拥有相似目标的主体也可能因认知或治理方式不同而行动不同。

六元组是**描述框架**，并不假设每个分量均可准确测量，更不要求集体主体具有统一认知或意志。分量内部可以再区分不同部门、群体及其冲突。

**集体主体分量的证据标准。** 以指定决策、时段与组织层次为单位，分别检索下列证据。单份宣言、单次行为或单个结果均只能作为线索。

| 分量 | 优先观察 | 独立核对 |
|---|---|---|
| $`Cog`$ 认知结构 | 同期风险评估、预测、对事实或因果关系的判断 | 后续信息搜集、数据修订或对新信号的反应 |
| $`Goal`$ 目标集合 | 目标排序、授权任务、明确的取舍或不可接受条件 | 预算、人员投入或有证据的实际取舍。须另查权限与资源约束 |
| $`O`$ 内部治理 | 谁有提议、授权、否决、问责或执行权限 | 一次或多次具体决策中实际沿何种程序形成结果 |

每项定值至少使用两类相互独立的材料，例如同期文本或程序档案，加上行为轨迹、资源记录或程序执行记录。转载同一材料按一个来源计。文本与行为冲突时先核对观察层次、时序及约束。仍不能区分时记为“不明”，并保留竞争解释。同一行为可提示多个分量，不能单独完成多个分量的定值。

## 5.2 主体资格的四项判据

判断一个群体是否适合作为某项研究中的集体行动主体，应分别考察：

| 判据 | 操作性问题 | 可能证据 |
|---|---|---|
| 边界可识别性 | 能否在研究问题中识别参与者及其范围？ | 成员记录、参与规则、项目边界、实际行动网络 |
| 资源组织度 | 是否能够取得、动员或分配与行动有关的资源？ | 预算、代码仓库、人员投入、设备或组织记录 |
| 内部协调机制 | 是否存在可重复的协调、决策或行动机制？ | 规则、会议记录、维护流程、实际协调事件 |
| 代表或等效表达机制 | 是否有人或某种分布式程序能够对外表达、作出承诺或协调行动？ | 授权、治理章程、维护者程序、共识与投票机制 |

四项判据可以分别按 **0＝证据支持其缺失、1＝部分或间歇存在、2＝在任务窗内相对稳定存在** 编码，并保留“不明”选项。

**四项分别报告。** 证据不足、冲突未决或只有单一证据类型时优先记为“不明”。0 需要覆盖充分且支持机制缺失的证据。1 指局部或间歇运作，2 需要重复轨迹证明机制在相应任务窗稳定发挥作用。由两名编码者使用同一规则独立编码，保留裁决前的结果、证据、分歧条目及复核依据。分歧未解保留“不明”。单人试编码只能用于调整手册。

## 5.3 三类工作性区分

1. **身份或统计类别：** 可以被识别，但没有足够证据表明其具有持续集体行动能力。
2. **情境性集体行动主体。** 在特定事件或任务中，有证据显示该群体能够动员资源并协调行动。它可以是一次性团队，也可以是尚在形成的组织。
3. **制度化集体行动主体：** 在研究时段内，具有相对持续的资源组织、协调及代表或等效表达机制。

三类描述随任务和观察窗改变。单位可以形成、暂时组织、解散或退回松散状态，类别之间没有固定发展顺序。主体资格的研究编码不涉及对群体价值或政治地位的裁决。

**判据的适用界限。** 临时联盟、快闪群体和一次性响应网络以事件生命周期为观察窗。若可观察到任务边界、资源动员、协调和代表或等效表达，可登记为该事件中的临时集体行动主体，并写明作用范围。无正式代表时，可用可追溯的分布式授权或一致对外协调作为等效证据。未找到协调证据的涌现过程以关系或事件为分析单位。每个新事件须按其边界和证据重判主体资格，类别不会自动延续或升级。个体和纯统计类别分别使用适合的分析单位。个体的内部治理可用自我调节与行动协调描述。

# 六、资源自身属性与资源—系统耦合

## 6.1 资源自身及访问属性

| 符号 | 属性 | 工作性定义 |
|---|---|---|
| $`V`$ | 竞争性 | 一方使用某资源是否、以及在多大程度上减少他人的可用量或可用质量 |
| $`X`$ | 排他性 | 在既定技术、法律和制度条件下，限制他人获取或使用的能力 |
| $`M`$ | 可复制性 | 在指定条件下复制资源所需的成本、时间与复制结果的保真程度 |

**重要限定：** 本书沿用“资源自身属性”这一模块名称，但 $`X`$ 不是脱离制度和技术条件的纯天然属性；$`V`$ 和 $`M`$ 的表现也可能随规模、拥塞、技术及使用场景变化。因此，三者均须说明观察条件。

例如，复制一份源代码的边际成本可以很低，但持续维护、获得贡献者信任和建立用户生态并不因此没有成本。

## 6.2 资源—系统耦合属性

| 符号 | 属性 | 工作性定义 |
|---|---|---|
| $`Sub`$ | 可替代性 | 在事先规定的功能、质量、容量和服务时窗内，具备资格的候选来源或路径及其覆盖程度 |
| $`K`$ | 关键性 | 指定资源、节点或网络边中断时，在给定边界、基准和时间窗内对参照功能造成的影响程度 |
| $`B`$ | 瓶颈程度 | 在指定网络与功能范围内，相关流动或功能必须经过某节点或少数节点、且难以绕行的程度 |
| $`Dep_a`$ | 依赖非对称性 | 针对同一功能、基准期和共同度量口径，由两向依赖派生的差异 |

这些属性属于资源与系统的关系，而非资源脱离情境后固定不变的性质。同一资源在不同系统、时期和功能中可能具有不同的关键性与可替代性。耦合条件如何影响行动空间，见 §11.7 的 H6。

**关键性与瓶颈不等同：** 某资源可能高度重要，却有多个可替代供应渠道；某节点可能位于唯一通路上，但其所承载功能对研究对象并不重要。

**替代资格与迁移成本分别登记。** $`Sub`$ 记录满足功能及运行要求的路径，按具备资格、尚待验证和未知分别登记。$`SD`$ 描述迁移到有资格路径的成本。材料足以支持研究边界内无可行路径时记为 NP，资料不足时记为“不明”。两类情况都不填入成本数值。$`Sub`$ 与 $`SD`$ 不能互换，也不定义为倒数。详见 §14.2。

# 七、关系、领域向量与连接状态

## 7.1 领域关系向量与网络关键性

【定义 D12｜领域关系向量】

用 $`C_j`$ 表示领域连接，$`Dep_j`$ 表示有向依赖档案，$`I_j`$ 表示规则与协调整合。将其用于主体 $`u`$ 与 $`v`$ 在领域 $`j`$、时点 $`t`$ 的关系，定义如下。

```math
\mathcal S_{uv,j,t}=(C_{uv,j,t},Dep_{uv,j,t},I_{uv,j,t}),\qquad
Dep_{uv,j,t}=(Dep_{u\leftarrow v,j,t},Dep_{v\leftarrow u,j,t})
```

省略已明确的主体和时点时，简写为 $`\mathcal S_j=(C_j,Dep_j,I_j)`$。

| 分量 | 含义 | 观察规定 |
|---|---|---|
| $`C_j`$ | 连接 | 记录指定关系的通道、流量、频率或可达性，必要时分方向 |
| $`Dep_j`$ | 有向依赖档案 | 分别记录两端为维持指定功能对对方的依赖，注明功能、基准和期限 |
| $`I_j`$ | 规则与协调整合 | 记录可由双方实际使用的共同规则、互认和持续协调。多边安排仅编码其对该对关系的适用与执行证据，据 D9 可包括稳定惯例 |

依赖非对称性 $`Dep_a`$ 仅在相同参照功能、相同基准期，两向可映射到同一标尺时从双向档案派生。等量尺度可记录带方向的差值，统一锚定的有序等级只记录顺序与方向。不可比或缺失时保留两向档案并将 $`Dep_a`$ 记为不可计算。下标 $`\mathrm a`$ 表示非对称。

**网络关键性独立登记。** $`K_{x,j,t}`$ 衡量领域 $`j`$ 的网络中，资源、节点或指定网络边 $`x`$ 中断对参照功能产生的影响。记录附网络边界、评估对象、基准、时间窗和中断情景。原 $`K_j`$ 保留为各项条件均已交代时的独立简写。若考察一段二元关系对全网的贡献，可评估移除该网络边的后果，将结果登记为网络层 $`K`$。瓶颈程度 $`B`$ 衡量路径约束，关键性 $`K`$ 衡量功能后果。

## 7.2 连接状态向量

【定义 D13｜连接状态】

以 $`I_f`$ 表示接口连续性，$`O_r`$ 表示主体间组织关系连续性，$`Rec`$ 表示身份认同与相互承认。对指定关系或分叉路径，先登记参照时点或窗口 $`t_0`$，再在时点或窗口 $`t`$ 记录以下剖面。

```math
L(t\mid t_0)=(I_f,O_r,Rec),\qquad Rec=(Rec_{\mathrm{id}},Rec_{\mathrm{ack}})
```

$`L`$ 含三组记录，第三组 $`Rec`$ 的值是有序对。实测档案含四个基本字段，分别填报并允许单项记为“不明”。数值分析可将该记录展开为四列。

| 字段 | 含义 | 可能的证据 |
|---|---|---|
| $`I_f`$ | 接口连续性 | 指定版本或接口的兼容、互操作及协议延续 |
| $`O_r`$ | 组织关系连续性 | 参与、人员联系、共同行动或治理记录 |
| $`Rec_{\mathrm{id}}`$ | 身份认同连续性 | 参与者对共同身份的表述、调查或归属记录 |
| $`Rec_{\mathrm{ack}}`$ | 相互承认连续性 | 接纳、资格认可、互认或针对对方作出的行为 |

基准须覆盖同一关系、功能、单位和口径，通常取冲击或分叉前的窗口。分叉尚未形成两项目时，先按预先登记的映射规则识别原项目中后来分属两支的成员及其既有协作。若历史关系无法确认，仍可报告当前关系特征，连续性和断裂程度记为无法判定。双向互通或相互承认可分向记录。

历史分叉研究须记录成员身份匹配依据、分支归属所用的证据和不确定项。优先使用可核查的分叉前共同工作记录及分叉后各支的明确角色或贡献。跨支身份、别名争议和材料只留单次痕迹的成员单列。用更严格的一套归属规则重新编码，记录配对或结论是否改变。共有祖先、自动镜像和单方移植分别记账。

## 7.3 分叉、阻断与隔离不能硬性并列

【定义 D14｜分叉】

分叉是主体、项目或组织从原有路径中产生并行发展路径的操作或过程。技术上的复制或 Fork 本身不证明社会关系已经分裂。

【定义 D15｜阻断】

阻断是某主体或事件导致既有通道、准入或关系受到实质中止或限制的机制。是否存在强制、由谁实施以及持续多久，须由事实判断。

【定义 D16｜隔离状态】

隔离是相对于指定基准，预先选定的多个关系字段跨规定时段持续低于连续性阈值的状态。编码时须注明分析对象、必需字段、阈值、持续窗口及缺失情况，并以基准和多个后续观测支持判断。

**位置区别：** 分叉描述操作或演化过程；阻断描述作用机制；隔离描述状态。三者可以重叠，不能视为互斥且完备的三分类。

$`L`$ 有助于描述它们的关系后果，但仅凭某一时点的 $`L`$ 无法确定其形成原因、是否由外力阻断，或是否不可逆。四个观测字段在同一时点同时走弱，仍需纵向证据判断是否形成持续隔离。可逆性须通过长期观察和明确的恢复条件判断。

# 八、多维整合与跨层、跨领域整合差异

## 8.1 多维整合

【定义 D17】

整合应按研究问题区分领域与层级。例如：

- 技术整合：协议兼容、标准互认及共同运行能力；
- 经济整合：交易、分工及相应协调规则；
- 治理整合：共同决策、争端处理或规则执行安排；
- 安全整合：安全合作、风险协调及可信承诺；
- 社会与文化整合：共同参与、身份认同及相互承认。

这些只是工作性领域，不构成唯一分类。不能将单一领域的高整合直接认定为整个系统高度整合。

## 8.2 跨层与跨领域整合差异

【定义 D18｜整合差异】

**跨层整合差异（Cross-layer Integration Divergence）** 指在可比时间窗内，与同一研究对象或功能有关的不同组织层级之间，规则与协调整合状态呈现可辨认的差别。同一层级中经济、技术、治理或安全等领域之间的差别称为**跨领域整合差异**。两类差异可同时出现。缺乏等值量表时，分列各层级或领域的整合剖面与依据。

“失衡”仅用于给出明确参照的功能评估。须注明哪项功能需要怎样的协调、参照基准从何而来、对谁适用，以及适用时限。参照可来自既有协议的服务要求、可独立核查的风险处置门槛或适当的比较案例。整合程度不同本身仅构成差异。

【命题 H1｜协调缺口与条件性脆弱性】

在关键功能高度依赖且替代受限时，相对达到独立事前协调基准的同类系统，有基准可核查的协调缺口预计对应更大的可比冲击后功能损失。基准取自事前生效的协议、服务要求、行业标准或既有演练。研究者须重建争端前基线、缺口形成、冲击和结果的时间链，并追踪缺口是否先于所研究的争端或由早期冲突造成。若无法区分顺序，或只从损失反推缺口，该记录作描述性材料。最低纳入标准与失败规则见 §14.5。

正式半导体案例只纳入有来源与口径的实测记录或有可核查依据的序数判断。早期讨论中的示意分数不进入案例。

# 九、五类权力、替代距离与咽喉点

## 9.1 五类权力

【定义 D19｜权力】

本书将权力理解为主体在特定关系中影响他人可选行动、行为、资源获取或规则结果的能力。潜在能力、实际使用和最终效果必须分开。

本书用五类结构性权力描述社会技术与制度网络。这一划分非穷尽，允许重叠。每次事件按主要实施渠道登记，有独立证据时可附次级渠道，汇总时按事件去重。工作性权力向量如下。

```math
\mathbf P=
(P_{\mathrm{dec}},
P_{\mathrm{acc}},
P_{\mathrm{res}},
P_{\mathrm{att}},
P_{\mathrm{exp}})
```

| 符号 | 权力类型 | 典型来源 |
|---|---|---|
| $`P_{\mathrm{dec}}`$ | 正式决策权 | 授权、职位、投票和规则制定 |
| $`P_{\mathrm{acc}}`$ | 技术或制度准入权 | 接口控制、认证、代码合入、平台或协议准入 |
| $`P_{\mathrm{res}}`$ | 资源控制权 | 对资金、材料、设备、人才或基础设施的控制 |
| $`P_{\mathrm{att}}`$ | 注意力分配权 | 对信息可见性、议程和关注机会的影响 |
| $`P_{\mathrm{exp}}`$ | 专业影响力 | 知识、技能、可信度和声誉 |

制度化强制与制裁另标行动方式，并按实际渠道登记，例如批准限制的正式决策或执行限制的准入控制。主渠道取最直接改变对象行动条件的途径。无法区分时备注并列渠道。控制议题进入讨论范围时，按实际渠道记正式议程权或注意力分配权。直接物理暴力与军事强制在五类之外单列，记录其对网络连接、资产存续和功能的可观察影响。行动是否获得授权另行编码。

## 9.2 功能性替代距离

【定义 D20】

对指定目标主体、原功能、通过功能资格的单条替代路径及观察时限，定义如下。

```math
\boxed{
SD=
(c_{\mathrm{time}},
c_{\mathrm{finance}},
c_{\mathrm{tech}},
c_{\mathrm{org}},
c_{\mathrm{inst}})
}
```

| 分量 | 所指成本 |
|---|---|
| $`c_{\mathrm{time}}`$ | 建立、迁移并稳定运行替代方案所需时间 |
| $`c_{\mathrm{finance}}`$ | 投资、运营、转换及可能损失的财务成本 |
| $`c_{\mathrm{tech}}`$ | 技术研发、兼容、性能和安全验证成本 |
| $`c_{\mathrm{org}}`$ | 人员、技能、供应商、协作和运营组织调整成本 |
| $`c_{\mathrm{inst}}`$ | 法律、许可、合规、合同、信任与制度调整成本 |

$`SD`$ 为逐路径记录。先对同一功能和口径逐维比较，五维均不高且至少一维更低时，方可判一条路径成本较低。各维交叉时保留互不可比结果，也可使用事先指定的主维度检验。合成只在事前登记同尺度归一化、权重和敏感性方案后进行。NP 与不明均留在成本向量之外，见 §14.2。

其与五类权力存在**交叉映射**：例如技术替代可能改变准入权，也可能改变资源控制权；制度迁移成本可能影响多种权力。二者不作一一配对。

## 9.3 咽喉点权力命题

【定义 D21｜咽喉点】

在特定网络与功能中，路径约束 $`B`$ 和中断的功能后果 $`K`$ 分别达到事先登记的条件时，可标记候选咽喉点。认定基于指定时点已存在的网络和独立功能反事实。新增潜在路径、迁移成本、控制者权限和施压结果分别进入后续档案。

网络功能关键性 $`K_{x,j,t}`$ 是研究边界内的网络层筛选门槛。有向依赖 $`Dep_{\mathrm{tgt}\leftarrow\mathrm{ctl}}`$ 衡量指定目标对受控功能的事前暴露，进入 H2 的关系层模型。一个节点对参照网络的功能后果很大，某个目标仍可能极少使用它。H2 在通过 D21 筛选的样本中比较，另取目标结果，避免用事后损失同时界定候选节点和检验权力。

【命题 H2｜咽喉点权力】

在同一功能和作用窗、节点瓶颈与实际控制达到门槛、真实干预可比的样本中，事前有向依赖和迁移约束较强且反制较弱的目标，预计承受更大的预先指定功能约束。迁移比较限于成本量纲可核对且符合预登记排序的可行路径，NP 单列。模型登记式如下。

```math
P_{\mathrm{choke}}=f(B,Ctrl,Dep_{\mathrm{tgt}\leftarrow\mathrm{ctl}},SD,Ct)
```

$`Ctrl`$ 为实际干预能力，由权限、管辖或技术控制记录核实。$`Ct`$ 为可实际动用的反制与约束，由独立的执行、复核或制度保障证据核实。$`Dep_{\mathrm{tgt}\leftarrow\mathrm{ctl}}`$ 用干预前实际服务份额、投入份额或既有合同暴露衡量。$`SD`$ 只用具体迁移方案的分项成本。控制、反制、暴露、迁移及干预后结果须分别记录，并交叉核查是否重复使用同一观察，见 §14.2。

$`Dep_a`$ 用于描述武器化情形中的依赖不对称。高依赖对高依赖和低依赖对低依赖可能有相同的依赖差值，因此模型直接复用目标一侧的有向依赖。原 $`Exp`$ 停用。用共同参照登记两向依赖、派生差异和迁移成本。比较单位不一致时应保留原档。已有结构能力但未实施的窗口用于研究 H7 的行动选择，H2 的主检验使用可观察的实际干预与目标功能后果。

$`f`$ 的函数形式和参数均待研究。开源代码的复制费用与重建维护团队、信任和配套生态的费用应分别考察。半导体的替代成本也须结合干预权、法律约束和反制能力评估。

# 十、系统韧性五维

【定义 D22】

韧性是指定系统在指定冲击情景和时间尺度下，维持、恢复或调整相关功能的能力及表现。用组织连续性 $`R_o`$ 衡量焦点系统内部组织运作延续。该维度与主体之间的组织关系连续性 $`O_r`$ 各有观察边界。

```math
\boxed{
\mathbf R=(R_a,R_o,R_i,R_{rc},R_{ad})
}
```

| 分量 | 名称 | 观察问题 |
|---|---|---|
| $`R_a`$ | 资产存续 | 关键资产、资源和基础设施在冲击中是否保存？ |
| $`R_o`$ | 组织连续 | 核心组织、协作与治理能否继续运转？ |
| $`R_i`$ | 系统完整 | 指定系统的重要组成和关系是否仍可共同实现核心功能？ |
| $`R_{rc}`$ | 恢复能力 | 受损功能能否以及多快恢复至预先说明的基准？ |
| $`R_{ad}`$ | 适应能力 | 系统能否通过调整结构、规则或功能应对变化？ |

五维可分别变化。以工厂为焦点时，$`R_a`$ 的资产盘点边界可限定为工厂管理的设备与基础设施。$`R_i`$ 的功能边界还需列明维持合格产出所需的外部投入和连接。设备盘点完整、生产功能中断可以同时出现。$`R_o`$ 观察该组织的班组或决策功能是否持续，$`O_r`$ 则观察该厂与指定外部伙伴之间的关系是否延续。适应可能经由系统重组实现，与原结构完整性产生冲突。

操作化必须回答：**谁的韧性、面对什么冲击、维持什么功能、在多长时间内、以什么代价、对谁产生影响？** 高韧性也可能使不公平或有害的结构存续。关于韧性维度的方向性预测，见 §11.8 的 H8。

# 十一、动态机制与条件性命题

## 11.1 分化—整合反馈

【机制 Mech1｜分化与整合的反馈】

1. 环境变化、知识积累或内部博弈产生新的分工和差异；
2. 差异可能提高互补性，也可能增加协调与兼容成本；
3. 主体可能建立规则、接口或共同治理机制；
4. 新的整合安排又可能改变资源分配、权力结构和后续分化方向。

这是可能出现的反馈路径，不是所有系统必须经历的固定阶段。

【假说 H3｜分工与共同完成】在已有兼容接口、可用协调机制且任务互补有事前证据的同类任务中，相比分工程度稳定的单位，新增互补分工的单位预计在约定时窗达到更高的共同完成率。任务互补据工作流程和职责接口判定，共同完成率据事先界定的任务和交付另行计算。冲突、投入、选择进入和任务难度属于竞争解释。逆向反馈另设研究问题。

## 11.2 相互依存的武器化

【定义 D23｜相互依存的武器化】

相互依存的武器化，是行动者利用网络中的依赖关系、信息位置或准入控制，对其他主体施加约束、压力或获取战略优势的过程。

【机制 Mech2｜相互依存的武器化】

条件由四项结构条件和一项行动决策条件组成。

### 四项结构条件

1. **关键节点：** 网络存在对某种功能或流动重要的节点或通道。
2. **实际控制：** 某行动者有能力影响该节点的使用、信息或准入。
3. **依赖非对称。** 两端针对同一功能和基准期、有共同度量口径时，以 $`Dep_a`$ 描述差异，并保留两向档案。不同功能或量纲只能并列，非对称条件记为不可判定。目标一侧依赖仍可由独立事前证据确认。
4. **替代与制约不足。** 依据路径资格和迁移成本档案分别确定替代是否受限，再用独立材料判定反制与外部约束。路径信息不足、确无可行路径和存在路径但迁移困难分别登记。

### 一项行动决策条件

5. **行动选择：** 控制者决定是否施压，并受到其对预期收益、自身损失、盟友协调、声誉、法律风险及长期替代效应等因素的判断影响。

按时序分别登记五项。结构能力使用事前网络与权限档案。行动决策使用同期授权或议程材料。实际实施使用执行记录。目标影响使用目标服务、投入或行为资料。政策效果另查目标是否按被提出的要求改变行为。审批停滞或口头劝导须有可核查的实际行为和归因证据。五项均可分别记为不明，详见 §14.1。

行动者可能误判，也可能出于国内政治、象征目的或错误信息而采取看似得不偿失的行动。因此，“预期收益覆盖成本”是可研究的决策假说，**不是所有武器化行为都必须满足的已证实事实**。

【假说 H7｜自伤约束与实际施压】

在结构能力和事先规定的触发机会可比时，事前预期自伤或协调成本较高的一组，预计在等长观察窗内实施率较低。锁定主成本维度、机会名册和实施判据，分别编码已实施、有证据支持未实施及不明。公告缺席不足以确认未实施。可检验性取决于能否独立取得事前成本和实际执行记录，具体失败规则见 §14.5。

【理论来源说明】本框架与 Farrell 和 Newman 对非对称网络及国家胁迫的研究对话；上面的“四项结构条件加一项行动决策条件”是本书的整理与扩展，不能归称原作者提出的同一定式。参见 [Farrell 与 Newman（2019）](https://doi.org/10.1162/isec_a_00351)。

## 11.3 效率—韧性的条件性关系

【假说 H4｜冗余、常态成本与冲击损失】

在同类服务、输出要求和关键架构可比时，撤掉原有后备能力的单位预计降低常态下每合格单位的成本，同时在后备原本覆盖的实际冲击下产生更大的承诺服务损失。与保留后备能力的单位或时段比较，分别报告常态成本和冲击窗服务损失，后者作为系统功能完整性 $`R_i`$ 的结果指标。两项均为主要结果，任一项有充分证据偏离预先登记的实质性方向即挑战联合预测。同期升级、负荷变化及成本与损失转嫁必须跟踪。

框架允许其他技术或组织改造同时改善效率与韧性。该类改造另行提出预测。

## 11.4 分叉、阻断与隔离的动态路径

【机制 Mech3｜分叉与关系重组】

分叉可能由创新、治理分歧、资源争议或外部压力引发。分叉后可能出现：

- 保留接口和合作关系的并行发展；
- 组织分离，但维持技术互操作；
- 一方阻断准入，另一方建立替代路径；
- 多种关系长期弱化，逐渐形成隔离状态；
- 重新兼容、恢复合作或再次整合。

路径分析须同时记录连接状态 $`L`$、行动者决策、外部冲击和实际互操作性。归类隔离须满足 D16 的基准、关系字段、持续时间和纵向证据标准。单次分叉、接口变化或单时点关系弱化只登记为事件或当期状态。H9 比较后续组织关系，见 §11.9。

## 11.5 自主性与相互依存

【定义 D24｜自主性】

自主性是主体在特定约束和关系中，形成、选择并执行重要行动方案的相对能力。自主性不等于完全不依赖他人，也不等于拥有无限选择。

【假说 H5｜可用退出与行动选择】

在高依赖且合同与治理环境相近的重谈或准入变动中，事件前已拥有在时间、费用和质量门槛内可用退出路线的主体，预计保留更多独立可执行的议价或运营选择。结果清单排除用来划分对照的退出路线本身，使用授权、预算、操作能力或实际行使记录核实其他选择。形式退出权、协商程序、规则约束和力量制衡另作记录，可预登记为分层因素。替代与退出的费用及对第三方的影响分别报告。

H5 沿用关系权力研究对依赖和替代机会的关注。它具体检验事前可负担的退出路线是否伴随重谈期间其他可执行选择的保留，并将两者独立测量。协商本身可以形成或保住其他选择，须作为竞争解释纳入设计。参见 [Emerson（1962）](https://doi.org/10.2307/2089716) 和 [Baldwin（1980）](https://doi.org/10.1017/S0020818300018828)。

## 11.6 反馈、适应与共演化

【机制 Mech4｜反馈、适应与共演化】

主体的行动会改变网络、资源与规则；被影响主体可能作出反制、适应或退出；这些反应又改变最初行动者的未来选择。

例如，对节点的限制可能在短期内提高控制效果，也可能在长期刺激替代网络建设。后一结果需要跟踪替代的实际可行性、成本和时间。

## 11.7 资源耦合与行动空间

【假说 H6｜资源约束经由替代空间影响行动】

在同一类功能和可比供给约束下，如果关键投入的事前功能合格路径较少，且存在可比应对需求，则预计主体在统一成本、期限与质量门槛下实际部署的合格应对方案较少。事前依据供应、认证或兼容资料评价关键性与替代条件，事后用部署、采购或运行记录独立编码应对结果。若控制初始规模、库存和冲击强度后，多个可比事件的方向稳定为零或相反，则 H6 受到挑战。

## 11.8 韧性的维度分化

【假说 H8｜资产存续与功能完整可分离】

在以系统自身为资产盘点边界、本地关键资产未直接受损而关键外部供给中断的系统中，与有可用缓冲的对照相比，预计缺少库存或替代路径的一组会出现较低的早期系统完整性 $`R_i`$，同时资产存续 $`R_a`$ 仍处于预先规定的高位。用独立的资产盘点与服务或产出记录判断两个维度，并事先登记阈值和时间窗。若相关冲击下两项持续同步、无可辨认分离，则此情景中的 H8 受到挑战。其余三维仍按原口径跟踪，具体方向由独立假说规定。

## 11.9 分叉后的社会关系

【假说 H9｜兼容性与组织关系延续】

在分叉前存在可确认的协作关系、起始规模和分叉原因可比的项目中，若分叉初期仍有可用共享接口，预计其后一个约定窗口内的跨项目协作下降幅度较小。用兼容测试记录初期接口条件，以独立的跨项目贡献和共同行动记录衡量后续组织连续性，另报告认同与承认。若可比事件中的后续组织关系下降幅度稳定无差异或方向相反，则 H9 受到挑战。单个可信的延续案例可反驳“分叉必然导致社会分裂”的强断言，但不足以检验这项方向性预期。

# 十三、案例研究计划与理论对话

公开资料可达到的层级不同。开源案例可继续尝试方向性研究，前提是历史版本往返和组织关系基线均可复核，并取得对照样本。半导体目前可做法规与企业披露层的过程追踪，金融目前可做规则、断开事件与机构范围的描述。三案各按证据覆盖推进。

三个案例分别承担不同任务。开源和半导体的既有讨论用于提出问题，此处确定下一步可调查的子系统和材料。金融作为待开展的迁移研究。已核对的公告与法规可确定事件和制度范围，命题的方向与效果仍须按第四篇的规则取证。

## 13.1 案例一　开源文字处理软件的分叉

【案例计划】以 2010 年 9 月 28 日 LibreOffice 从 OpenOffice.org 分叉并公布新治理安排为锚点。观察对象限于 **Writer 文字处理模块的 ODF 文档读写** 和参与该模块的维护者。基准窗为 2009 年 9 月 28 日至 2010 年 9 月 27 日，分叉后的观察窗至 2012 年 9 月 27 日。在记录中标出 OpenOffice.org 于 2011 年 6 月 13 日进入 Apache Incubator 的治理变更，防止把随后发生的转移都记作最初分叉的后果。[The Document Foundation 当日公告](https://listarchives.documentfoundation.org/www/announce/msg00000.html)；[Apache 孵化档案](https://incubator.apache.org/projects/openofficeorg.html)。

- **技术观察单位。** 固定历史版本与文档样本，按“文档样本 × 版本组合”记录打开、保存及往返后关键功能是否保留，分别报告两个方向。不同 ODF 规范版本及发布节奏进入比较档案。可从正式规范和双方代码档案建立可重复的文档测试。[OASIS ODF 1.2 规范](https://docs.oasis-open.org/office/v1.2/os/OpenDocument-v1.2-os.pdf)；[LibreOffice 核心代码镜像](https://github.com/LibreOffice/core)；[Apache OpenOffice 代码库](https://github.com/apache/openoffice)。
- **组织观察单位。** 以“预登记的维护者配对 × 季度”记录两支成员之间的共同修复、明确的跨项目审查、合并或补丁移植，以及稳定的协调往来。按分叉前共同项目档案先确定基线，分叉后分别用开发邮件与提交记录核对。共享祖先代码和自动镜像均单列。分支归属、相互承认或早期记录缺失时按字段记不明。[LibreOffice 开发邮件档案](https://listarchives.libreoffice.org/global/dev/)；[Apache 孵化档案的开发与提交记录入口](https://incubator.apache.org/projects/openofficeorg.html)。
- **可检验范围。** 先检视接口连续与组织连续是否能够分别观测。若要估计 H9 的方向，应从事先列出的可比项目分叉或具有可比口径的模块对照中选择样本。遇到接口不兼容但仍持续协作等情形，按相同规则登记。单一分叉的机制描述保留为初步线索。

[Writer 分叉公开档案试编码](../case-studies/writer-fork-pilot.md)附接口和组织字段的已查记录、基准与缺失。试编用于检查口径及资料覆盖。H9 的方向判定仍需可重复的历史版本往返、稳定的维护者映射、完整观察窗和预先确定的对照。

## 13.2 案例二　特定晶圆制造沉积设备的许可变化

【案例计划】以美国商务部工业与安全局（BIS）2022 年 10 月历史规则中原始 3B090.a 所列设备为范围，按具体条款记录生效与过渡日期，观察 2022 年 4 月至 2023 年 3 月。采用双层档案。[BIS 原始规则](https://www.federalregister.gov/documents/2022/10/13/2022-21658/implementation-of-additional-export-controls-certain-advanced-computing-and-semiconductor)。

- **公开档案。** 规则按“条款与设备范围 × 生效日期”编码，公司记录按“供应商 × 财季 × 地区或另有披露的全球业务类别”编码。两类报表口径独立。地区营收与全球业务类别不能合成设备在特定地区的交付值。当前可比较规则、披露时间和企业经营背景，支撑描述与过程追踪。[Lam Research 2022 年 10-K](https://www.sec.gov/Archives/edgar/data/707549/000070754922000107/lrcx-20220626.htm)。
- **细档案。** 仅在取得可核对的设备归类、接收方、交货及目标工序结果后，启用“供应商 × 同类设备 × 接收方 × 月”单位。届时分别报告事前供货、$`B`$ 的路径约束和 $`K`$ 的功能后果。H2、H6、H8 仍需各自满足 §14.5 的可比条件及独立结果要求。[实际查阅的档案与缺失字段](../case-studies/public-data-feasibility.md)。

### H7 的最小研究方案

在同一控制方和同一政策窗口内，先依据决策前已有的管辖权、目标功能和可核实的触发机会建立“设备类别 × 接收方类别”名册。以当时有权考虑限制、确实出现可比触发机会为入样条件，最终是否列入清单、是否申请许可及是否执行均作为结果或中间记录。进入结果编码前锁定同类设备与接收方的匹配规则和观察终点。若无法建立同一控制方下未实施机会的观察覆盖，只能做执行过程追踪。

- **成本档案。** 以决策前有时间戳的正式政策记录、磋商资料或可核查的产业暴露材料分别评估自身损失与协调成本。企业风险披露可说明供应商暴露。对控制方预期成本的判断仍需决策者材料或可核实的传导证据。
- **实施档案。** 用法规执行材料、可获许可或豁免记录，以及经交叉核验的企业执行披露判断已实施、确认未实施或不明。法规的公布、行政决定、实际执行、目标受影响和政策结果分列。无公开禁令但有可验证的审批停滞时，须查明它是否可归因于相关干预。同期授权记录、合规披露和可靠的实际交易记录可提供核对依据。
- **判断规则。** 在共同的观察终点比较高、低预期成本组。保留游说、法律限制、政策目标差异和审批能力等竞争解释。按 §14.5 预设最低可比性、结果可观测性和失败阈值。没有可靠的事前成本证据，或非实施记录无法辨认时，H7 仍不可判定。

## 13.3 案例三　指定银行的跨境金融报文接入

【案例计划】以欧盟《2022/345 号条例》所涉首批指定机构为范围，记录 2022 年 3 月 12 日 Swift 报文服务断开。采用双层档案。[法规和机构名录](https://eur-lex.europa.eu/eli/reg/2022/345/oj/eng) [Swift 执行公告](https://www.swift.com/news-events/news/message-swift-community)。

- **公开档案。** 以“机构 × 规则或断开事件”核实范围、时间和公开实施记录。公开的替代网络接入公告须能对应到指定机构和服务，才能单列接入。网络总体统计独立呈现。接入公告与全网流量均无法识别指定银行的使用量或结算结果。

## 13.4 与 Ostrom 多中心治理的理论对话

【理论对话】把 Ostrom 对共同资源与集体行动的研究作为第 26 章的对话对象。比较可独立决策的治理中心如何建立共同规则、履行监督和安排争议处理。研究各中心是否具有实际决策空间，协调机制如何跨层运行，权力及协调成本如何分担。多中心性本身无法确定分配是否公平或治理是否有效。对话旨在划清解释范围。要从具体治理研究推及其他文明子系统，需要另给跨层传导证据和比较设计。[Ostrom（2010）](https://doi.org/10.1016/j.gloenvcha.2010.07.004)。

# 十四、变量操作化、证伪与边界条件

首次试编可使用[一页编码清单](../methods/pilot-checklist.md)。本节保留完整口径，清单按现场填报顺序安排。

## 14.1 变量登记与识别门槛

为每项测量登记主体与方向、资源或节点、网络边界、目标功能、基准与观察窗、指标、数据来源、量纲、阈值、缺失处理和不确定性。对有向量记录双方角色。对资源与系统耦合属性记录被评估对象和参照功能。改变功能、层级或时窗时建立新记录，并注明与原记录的可比范围。

同一证据可以包含不同信息。例如，一份合同可以分别提供承诺用量和暂停供货权限。记录须精确到字段或原文位置，标明每条证据对应哪个变量、在哪个时点形成，以及是否与其他变量共用来源或代理指标。用同一个事实或派生指标衡量两项构念时，选择其主要用途并说明理由。若无法分别观察，保留联合描述，标注“无法分离识别”。多个变量的取值可能真实共变。分开取证只降低定义循环与重复计入的风险，变量之间的统计依赖与因果顺序仍需检验。缺少识别所需的记录时，可发布描述，暂缓方向性命题判定。

**试编码必须报告证据重叠。** 对有向依赖与替代距离（$`Dep`$/$`SD`$）、路径瓶颈与网络功能关键性（$`B`$/$`K`$）、实际控制与有效反制（$`Ctrl`$/$`Ct`$）分对登记。先给各变量实际用于定值的材料两个编号，分别指可回溯的原始来源和底层事实或数据序列。转载沿用来源编号。改写、分列或派生自同一观察的指标沿用事实编号。对来源和事实分别报告共同编号数与去重后合并编号数，并可列出重叠比。任一变量缺少可用证据时，该对记“不可评估”。

重叠报告还要指出关键结论依赖哪些共同材料，以及是否能剔除共用事实、更换独立代理或去掉共同来源后复算。资料允许时实际复算，记录方向、可用单位数和结论是否改变。同一个合同中的供货比例与停供权限可以是不同事实。两项定值若只能依赖同一事实，且缺少可作敏感性分析的独立材料，降为联合描述并记“无法分离识别”。重叠比没有跨案通用阈值，因果识别也需另行说明。

H1 的参照功能与协调义务须有结果发生前形成的依据，例如既有协议、适用标准、事前演练或按预先规则选出的同侪配置。按既有冲突、协调状态、触发冲击、结果出现分别记录时间。若资料只能证明协调缺口早于结果，却无法辨别它是否已由既有冲突造成，则保留时序描述，待补可识别证据。H7 分别登记干预能力、事前决策、实际实施、目标所受影响和政策效果。已公开宣布但缺少执行证据，实施记为“不明”。行政延迟或非正式限制须有可复核的行为、权限与归因证据。可信的未实施需覆盖约定的机会窗，并有足以观察实施的记录。

## 14.2 核心指标与去重规则

| 变量或记录 | 观测与编码 | 分离或限制 |
|---|---|---|
| 有向依赖 $`Dep_{u\leftarrow v,j,t}`$ | 以事前窗口内 $`v`$ 实际承担的功能投入或服务份额、已承诺给付份额等为观测。注明分子、分母、方向、单位和基准，并区分实际用量与合同口径 | 依赖指标使用既有功能关系的独立观测。迁移时间、替代价格、适配成本及由它们构造的锁定分数均归入替代测量 |
| 依赖非对称性 $`Dep_a`$ | 双向档案针对同一功能、同一时间窗并可映射到同一度量口径时，按事前登记的有向差或共同序数锚点记录。校准过的有序等级只比较顺序 | 禁止跨量纲相减或对序数等级作差。条件不齐时并列保留档案，标记不可比。一方有向依赖可独立成立，双向资料不可比时无法据此判断不对称程度或可胁迫性 |
| 瓶颈程度 $`B`$ | 在给定网络边界、参照功能和基准状态下，登记准许纳入的既有路径及其结构口径。可用经节点的流量比例、是否为必经节点、预先界定的现行绕行路径数量等 | 结构路径指标与特定主体能否迁移、迁移成本分开。若用同一流量份额同时构造 $`B`$ 和 $`Dep`$，须有独立的拓扑证据才能将两者作分离分析 |
| 网络功能关键性 $`K_{x,j,t}`$ | 在预先界定的范围与时窗中，评估移除或中断特定资源、节点或边 $`x`$ 时，参照功能相对基准的损失 | 报告中断情景、反事实和损失承担者。仅有流量集中资料时可评估路径，功能损失须另有证据。H2 的事前指标不得用同一事件事后的目标影响反推 |
| 可替代性 $`Sub`$ | 先登记可查的路径或来源清单，再按预设的功能等价、质量、容量、基准期限内的供应与运行标准及准入要求审查资格。分别标记可行、潜在但尚未证实合格、证据不足，记录口径内合格路径数或经校准的等级 | 路径资格阶段使用独立的供应、认证、兼容和准入依据。可负担性、切换所需时间与迁移难度留给成本档。覆盖充分且有明确依据排除所有路径时记 NP。未查到资料、尚未完成核验以及保密资料无法取得时记“不明” |
| 功能性替代距离 $`SD`$ | 以目标主体、参照功能和明确路径为单位，对已确认为可行的路径记录迁移所需时间、财务、技术、组织和制度五项成本及来源 | NP 不转换为成本数值。已知有可行路径但成本证据不足时，保留缺失分量或有依据的范围。多个分项若采用同一成本事实，应说明口径并避免重复累计 |
| 实际控制 $`Ctrl`$ | 以事前授权条款、服务权限、监管管辖与可核实的节点干预手段等观察谁能采取何种干预 | 用实际实施记录另判行动发生，用结果档案另判影响。仅有纸面权力且执行能力无法核实时，分别提报 |
| 有效反制与外部约束 $`Ct`$ | 记录独立于迁移方案的可执行约束，例如适用的复核、救济或集体约束机制，附适用范围、启动记录及作用时窗 | 与 $`Ctrl`$ 分开取证。目标迁移方案在 $`Sub`$ 和 $`SD`$ 档案中单列，其他缓冲如库存另记。相同的替代路径不重复计作反制 |
| 规则与协调整合 $`I_j`$ | 在领域 $`j`$ 中登记双方适用的正式规则、稳定惯例及其执行、争端处理与共同运行记录 | 分别记录规则存在与实践效果。多边安排只编码适用于该二元关系的义务和可观测实践 |
| 接口连续性 $`I_f`$ 与组织关系连续性 $`O_r`$ | 前者用接口、版本、互操作与协议延续取证，后者用原单位之间持续合作、人员参与、治理和共同活动取证 | 以指定关系和历史基准为单位。单次接触只说明当期状态。隔离的持续性须以多时点资料说明 |
| 身份认同 $`Rec_{\mathrm{id}}`$ 与相互承认 $`Rec_{\mathrm{ack}}`$ | 分别记录自我归属与对方的实际接纳、互认、拒斥等行为 | 报告群体内部差异。缺少历史基准的材料只描述当期，两字段可分别缺失 |
| 资产存续 $`R_a`$、组织连续 $`R_o`$ 与系统功能完整 $`R_i`$ | 先固定资产盘点与功能服务的边界。$`R_a`$ 由资产清册和损毁记录取证，$`R_o`$ 由系统内部治理、组织或运营能否持续取证，$`R_i`$ 以既定功能的服务、产出或关键流程实现程度取证 | 同一资产仍可存在而生产服务中断。$`R_o`$ 以指定系统或组织为单位，$`O_r`$ 以主体间既有关系及其历史基准为单位。此后按各自时窗另记恢复能力 $`R_{rc}`$ 和适应能力 $`R_{ad}`$ |

**检验中的变量分工。** H2 先按 D21 以事前结构路径和功能中断证据分别认定 $`B`$ 与 $`K`$，再独立记录实际控制、有向依赖、替代成本和有效反制。若事前只能判断存在结构瓶颈，缺少可信功能中断证据，则候选咽喉点的资格待定。H2 的结果使用干预后实际行动限制，数据范围与可见性按 §14.4–14.5 说明。H5 若以可负担退出作解释，需要在谈判前依据合格路径与事前成本门槛判定可用性，再独立观察谈判后仍可实际采取的行动。H6 将事前路径资格档案与事后部署记录分开。仅部署一种方案可能出于任务需要很少、策略可集中或资源不足，案例须记录真实需求与其它竞争解释。

## 14.3 比较、数值与不确定性

替代方案先逐路径报告 $`SD`$，统一比较对象、参照功能和方向。向量分量均按“成本越低越有利”比较。若一条路径各维成本均不高于另一条，且至少一维更低，则称其成本向量帕累托占优。时间更短却制度成本更高、分量缺失或可信范围重叠使方向无法判定时，保留分项比较，标明无法定序及其原因。

主体有多条路径时，报告可行路径的成本剖面、未被其他路径占优的集合及必要的分维上下界。不得把不同路径各自最低的成本拼成一条可兑现的路径。主体之间若要区分“替代距离较大”，应事前选定同类路径、单独比较决定性维度，或给出可比较的统一成本门槛。必须生成合成指标时，事前登记归一化、权重、对缺失量的处理和敏感性分析，公布合理权重变化是否改变结论。$`Sub`$ 与 $`SD`$ 分别回应可行路径有多少和逐条迁移要付出多少，两者不作倒数或简单换算。

案例中的数值须附指标来源、基准、量纲、划档或归一化规则、缺失及不确定性。适合构造统计区间时说明模型和假设，资料不足时可按清楚锚点报告类别或证据区间。未评级的观测不填零，不将“不明”算作“无可行路径”。原讨论中的半导体整合度示意分数不得进入正式案例。

## 14.4 从研究方案到预登记

本章规定 H1–H9 进入案例检验的最低要求。每项研究须在读取主要结果或开始结果编码前锁定以下内容。使用已知历史结局时，要记录研究者事前已知的信息，保留档案选择和编码时间线，尽可能由独立编码者处理结果或用事先划定的保留材料复核。

1. **纳入规则。** 写明命题版本、分析单位、参照功能、观察窗、事件及对照样本的来源。按 §14.5 的最低可比标准逐条登记理由。记录所有候选及剔除理由，对预期方向相反的材料使用同一条规则。
2. **测量规则。** 分别登记前置条件、主要结果和机制证据的来源、量纲、阈值、缺失编码及误差范围。预先指定需要对齐的关键条件和允许偏差。其余竞争解释作为需登记的协变量、分层因素或敏感性检查，资料不足时降低结论强度。发现反例后不得把这些因素改成入选门槛。
3. **判定规则。** 预先给出该研究的一项主要比较和方向、具有实质意义的最小差异，以及支持、挑战和无法判定的界线。联合预测须写明每项结果如何判定。有可靠量化条件时，报告与研究设计匹配的不确定性区间。区间能排除具有实质意义的预期效果，才可把近零或反向结果列为挑战。数据不足、区间同时容纳预期和相反解释时，记录为无法判定。定性研究对应登记达到主张所需的事件序列、相反的观察和判定依据。
4. **试编码与变更。** 用未进入正式检验的材料或遮去主要结果的样本试编码。确认两类核心证据可分别取得、最低窗和对照可实现、缺失能区分为“不明”或有证据的缺失，并记录编码分歧。试编码未通过时可修改设计并留痕，再锁定适用规则。事后调整另列探索分析，并同时报告按原规则得出的结果。

最低可比标准用于纳入同一项检验。只须满足已登记的核心条件和允许偏差。下表提供各命题的登记要求，具体时间和测量阈值按研究对象确定。蓝图中的方案属于待预登记的研究设计，各案例的档案覆盖和指标可用性须经试编核查。

**单一强反例的作用。** 事前登记所检验的是必然或必要条件、机制链条，还是组间方向性倾向。对必然或必要的说法，一个符合范围、满足原定必要辅助条件且由独立记录证实的相反观测即可反驳。对机制链条，若预定必要环节在观测充分时没有出现，且结局仍出现，该案例中的机制归因受到挑战。对方向性倾向，强反例可挑战适用边界，总体方向须按登记设计判断。经核实的未施压机会，在可比机会与事前成本可测的条件下可进入 H7。H2 需要实际干预及目标后果。分叉后协作延续可反驳“分叉必致分裂”，H9 的组间方向须另用可比样本评估。

## 14.6 H7 的最小可行研究方案

以同一控制者、相同法定权限和同类触发事件下的两组可识别机会为单位。先从政策议程、资格规则或同期会议材料建机会清单，纳入后来实施与后来未实施的情形。锁定一种事前自伤成本指标，例如决策时已公开的受影响业务份额或同期可核实的内部风险评估。用独立执行记录或核实过的替代资料编码实际实施。记录授权、国内压力及事件严重性，比较实施率和不明病例在合理上下界内能否改变方向。两个机会组可用来试编码和检查可比性，最终检验所需的单位数、观察覆盖和失败阈值须据试编码结果另行预登记。

机会分母须独立于最终管制清单和已披露申请。公告可用于编码公布范围。只有机会已被独立识别且观察覆盖足以核实执行渠道时，才可编码为“确认未实施”。只有结果清单时，保留所列范围及有证据的执行过程，实施率记为不可估计。详见[半导体、金融与 H7 资料核查](../case-studies/public-data-feasibility.md)。

以已公开实施案例为起点可能漏掉止于威胁或协商阶段的事件。这是 H7 分离机会、威胁、决策和实施的一项选样理由。参见 [Drezner（2003）](https://doi.org/10.1017/S0020818303573052)。

## 16.1 索引与类型约定

- $`i`$：主体编号。

- 粗体 $`\mathbf P,\mathbf R`$：向量；分量使用带语义下标的符号。
- 每章首次出现的分量写明全称。特别是规则与协调整合 $`I_j`$、接口连续性 $`I_f`$、主体间组织关系连续性 $`O_r`$ 和系统内部组织连续性 $`R_o`$。简写省略的索引须由上下文确定。
- 同一字母在标量、向量及上下标中的使用，必须以定义和对象为准；不得仅依靠字体差异承担全部区分工作。

**仍需注意的可读性风险：**

- $`I_f`$ 是接口连续性，$`I_j`$ 是领域规则与协调整合；二者不同，首次出现必须写全名。
- $`O_r`$ 是主体之间组织关系的连续性，$`O`$ 是某主体内部治理；对象和层级不同。
- $`K_j`$ 是带有网络与功能情境的关键性简式。需要比较或汇总多个对象时，分别保留各对象的中断情景，再说明汇总规则。
- $`R_o`$ 反映指定系统在冲击下的组织连续性，$`O_r`$ 反映主体之间既有组织关系的连续性；可能相关，但不能互换。
- $`Sub`$ 登记合格路径集合，$`SD`$ 按路径登记成本。高可替代性可以与高迁移成本同时出现，两个指标禁止互换或作倒数运算。

# 十七、文献与 APA 7 规范

## 17.1 引用原则

1. 正文使用作者—年份制，例如：(Ostrom, 2010)。
2. 直接引用须注明页码；转述也应在需要时标明具体位置。
3. 原始文献用于概念与理论溯源；综述用于识别争论；实证研究用于支持具体经验判断。
4. 不能仅凭理论相似就声称某作者“证明”了本书命题。
5. 参考文献按作者姓氏字母顺序排列；中文文献保留原题，按最终出版方案统一排列规则。
6. DOI 使用可解析的链接形式；数据集、报告和网页须按对应的 APA 7 类型著录。
7. 对文献未经核实的页码、观点、版本和出版信息，不得编造。
8. 建立内部文献登记表，记录来源类型、支持的具体命题、核查状态和可能的相反证据。
